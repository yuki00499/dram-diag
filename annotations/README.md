# DRAM detection v3 annotations

`dram_det_v3.json` is the canonical annotation source generated by the tracked
annotation application. YOLO text files are derived artifacts and must never be
edited as annotation truth.

The workflow is:

1. Define and review `configs/taxonomy_v3.yaml`.
2. Mark about 100 pilot images and freeze the taxonomy.
3. Complete primary annotation of all images.
4. Blind-review a stratified 20% sample plus every ambiguous or rare case.
5. Run `scripts/audit_detection_dataset.py --freeze`.
6. Run `scripts/export_detection_dataset.py` to create the YOLO dataset.

The frozen source records absolute pixel `xyxy` boxes, image-level quality
attributes, usability, review state, ambiguous objects, and ignore regions.
