# 选题评估与推荐

---

## 四方案总评

| 方案 | 视觉/神经网络 | 公开数据 | 芯片相关性 | 风险 | 建议 |
|------|:--:|:--:|:--:|------|------|
| 假冒/翻新芯片检测 | 很强 | 无，需自采 | 较强 | 标签真实性难证明 | 不作为首选 |
| 晶圆图缺陷检测 | 很强 | 很充足 | 很强 | 当前任务定义需修正 | **改造后首选** |
| EDA版图DRC检测 | 视觉+GNN | CircuitNet可用 | 最强 | EDA门槛较高 | **冲奖首选** |
| PCB弱监督检测 | 很强 | 很充足 | 一般 | 同质化、赛题关联偏弱 | 稳妥备选 |

---

## 方案一：假冒/翻新芯片检测 —— 暂不推荐

**核心问题**：不是模型，而是标签。

- 二手芯片 ≠ 翻新芯片
- 非官方渠道购买 ≠ 假冒
- 人工打磨样本不能代表真实造假工艺
- 1000张照片 ≈ 100颗物理芯片，数据增强不增加独立样本
- 随机按图片划分训练/测试集 → 同一颗芯片可能同时进入两边 → 结果严重虚高

**结论**：除非能获得经供应商、实验室或拆解检测确认的真假样本，否则应用成效和真实性很难经得住答辩。

---

## 方案二：晶圆图缺陷检测 —— 改造后首选

### 改名建议

> **面向长尾与未知缺陷的晶圆图智能诊断系统**

### 原方案的三个问题

1. WM-811K 是晶圆测试图（已标出 die 通过/失效），不是晶圆表面显微照片，不适合强调"表面缺陷定位"。
2. 只用正常样本训练属于"单类/无监督异常检测"，不是严格意义上的零样本学习。
3. 数据没有金属层、多晶硅层等工艺层信息，不能引入"不同工艺层缺陷率"约束；固定强化边缘区域可能压制 Center、Local 等缺陷。

### 修正后的任务定义

- 单一缺陷模式分类
- 多种缺陷混合识别
- 长尾类别识别
- 未知缺陷模式发现
- 预测不确定性与人工复核
- 相似历史晶圆检索和原因辅助分析

### 技术路线

```
晶圆测试图
  → 自监督 CNN/ViT 特征提取
  → 空间拓扑特征（径向分布、连通区域、方向性）
  → 特征融合
  → 单缺陷分类头
  → 混合缺陷多标签头
  → 未知模式检测头
  → 置信度、热力图和相似案例
```

### 实验指标

| 评估维度 | 指标 |
|----------|------|
| 已知类别 | Macro-F1、Balanced Accuracy |
| 混合缺陷 | mAP、Micro/Macro-F1 |
| 未知缺陷 | AUROC、FPR@95TPR |
| 可信度 | ECE 校准误差 |
| 泛化性 | 按 `lotName` 划分训练/测试集，避免同批次数据泄漏 |

### 公开数据

| 数据集 | 规模 | 说明 |
|--------|------|------|
| WM-811K | ~81万张晶圆图 | 仅部分带缺陷标签，类别严重不平衡 |
| MixedWM38 | ~3.8万张 | 正常 + 8种单一缺陷 + 29种混合缺陷；部分样本经过GAN平衡，须在报告中说明 |

### 优势

- 数据现成，模型路线清晰，训练成本低
- 与赛题"晶圆智能制造"直接对应
- "长尾 + 混合 + 未知模式 + 可信诊断"相比往届 YOLO 方案有明显差异

## 方案三：EDA版图 —— 冲奖首选

### 改名建议

> **基于视觉与图网络的版图拥塞及DRC风险预测**

### 原方案的修正

- 不建议从零生成 GDS 和 DRC 数据
- 不要写"替代传统 DRC 规则引擎"——DRC 是流片签核工具，神经网络无法保证零漏检
- 定位为**布局布线早期的风险筛查**，而非替代 DRC

### 技术路线

```
版图多通道特征图 + 网表图
  → CNN/UNet 视觉流
  → GNN 结构流
  → 跨模态融合
  → 拥塞热力图
  → DRC 风险热力图
  → 高风险区域和优化建议
```

### 公开数据

**CircuitNet**：公开发布拥塞、DRC、IR-drop、时延等数据与基线，包含 N14、N28，2026年5月新增 N45 数据。BSD-3-Clause 许可。

### 优势

- 与"AI+集成电路设计"高度相关
- 同时满足视觉识别和神经网络兴趣
- 可自然使用 CNN、ViT、GNN 和注意力融合
- 有公开数据，不必先搭完整 EDA 数据生成链
- 能做跨设计、跨工艺节点泛化

### 劣势

- 需理解布局、拥塞、网表、DRC 等基本概念
- 整体难度高于晶圆图方案

## 方案四：PCB 检测 —— 稳妥备选

### 公开数据

| 数据集 | 规模 | 说明 |
|--------|------|------|
| DeepPCB | 1500对图像，6类框标注 | MIT许可；检测裸板开路/短路/毛刺/针孔，非焊点或元器件缺陷 |
| VisA | 含4个PCB子集 | 像素级异常标注，CC BY 4.0 |

### 注意事项

- DeepPCB 检测的是裸板缺陷，不是焊点/元器件缺陷
- PCB 属于电子制造，不如晶圆图和 EDA 版图与"集成电路"直接相关
- 弱监督、少样本、增量学习、域适应同时做太多，建议只保留**"少样本 + 跨数据集泛化"**一条主线

## X-ray BGA 焊球检测 —— 有条件时的最优选

这个方向比晶圆图和普通 PCB 检测更贴合"芯片智能封测"。

### 是否可作为主赛题

> **有真实 X-ray 数据 → 优先做。完全拿不到真实数据 → 不做主赛题。**

目前公开可用的 AXI PCB defect detection 数据包含 32,377 张 X-ray 切片、92,208 个标注 ROI 和 22,872 个焊点，但仓库明确说明图像为企业专有数据，未公开。

### 改名建议

> **少样本 BGA 焊球 X-ray 质检系统**

若实际样本只是普通 BGA 焊接板，不建议使用"先进封装"。最好涉及 FCBGA、CSP、WLP、倒装芯片或微凸点，否则评委可能认为是普通 SMT 焊接检测。

### 检测对象（可靠可识别的缺陷）

- 焊球空洞及空洞率
- 桥连、连锡
- 缺球
- 焊球偏移
- 焊球尺寸异常
- 圆度异常
- 阵列间距异常
- 异物或异常高密度区域

> "虚焊、开路、Head-in-Pillow"等仅凭单幅垂直 2D X-ray 无法可靠确认，不要轻易作为主要分类标签。

### 技术路线

```
整板/封装 X-ray
  → BGA 区域和焊球阵列定位
  → 单焊球 ROI 自动裁剪
  → 焊球与空洞分割
  → 空洞率、圆度、面积、间距等量测
  → 已知缺陷分类
  → 未知缺陷异常检测
  → 封装级质量评分和可解释报告
```

### 模型选型

| 任务 | 方法 |
|------|------|
| 定位封装和焊球区域 | YOLO / RT-DETR |
| 焊球及内部空洞分割 | U-Net / SegFormer |
| 已知缺陷分类 | CNN / ViT |
| 未知异常检测（仅正常样本训练） | PatchCore / FastFlow |
| 几何特征融合 | 空洞率、圆度、中心偏移、相邻焊球距离 |
| 多角度注意力融合 | 如有同一封装的多个倾斜角度图像 |

### 核心创新点

> 神经网络识别 + 几何量测 + 少样本异常检测 + 不确定性提示

（比"纯深度学习分类"高一个层次）

### 数据获取渠道

- 学校微电子或材料实验室
- PCB/封装实验室
- 第三方无损检测机构
- 电子制造企业
- X-ray 设备厂商或代理商
- 手机、显卡、主板维修和返修机构

### 数据目标

| 级别 | 要求 |
|------|------|
| 最低可行性验证 | 30-50个独立封装/板件 |
| 正式参赛目标 | 80-150个独立样本，覆盖 ≥ 3种封装型号和 ≥ 3种缺陷 |

**注意**：一张板可裁出数百个焊球 ROI，但训练/测试集必须按"板件/封装"划分，不能随机按焊球划分，否则同一块板的焊球会同时出现在训练和测试中。

### 数据不足的补救

采用**"小规模真实数据 + 大规模合成数据"**（不可完全依赖合成）：

1. 从正常 X-ray 中分割焊球
2. 程序化生成空洞、偏移、缺球和桥连
3. 模拟噪声、模糊、散射、对比度和设备差异
4. 用真实少量样本做域适应和最终测试
5. 报告中单独展示"合成训练、真实测试"的效果

也可用 GDXray 等通用工业 X-ray 数据做预训练（仅帮助学习 X-ray 纹理，不能作为最终效果证明）。

### 建议指标

| 维度 | 指标 |
|------|------|
| 焊球检测 | mAP、Recall |
| 空洞分割 | Dice、IoU |
| 空洞率量测 | MAE、最大误差 |
| 缺陷分类 | Macro-F1、漏检率、误报率 |
| 未知异常 | AUROC、FPR@95TPR |
| 工程效果 | 单板处理时间、人工复核量降低比例 |
| 可信性 | 不同封装/设备/曝光条件下的性能下降 |

### 立项门槛

> **两周内能拿到 ≥ 20-30 个真实封装的 X-ray 图像（含一定数量可确认缺陷）→ 正式选择该方向；否则回到 WM-811K/MixedWM38 晶圆图方案。**

没有真实 X-ray 验证时，评委容易把项目判断为"合成数据上的概念模型"；有真实设备、样本和专家标注后，它会是几个方向中最有竞争力的一个。

---

## 最终推荐顺序

| 排序 | 方向 | 说明 |
|:----:|------|------|
| **①** | **晶圆图长尾、混合与未知缺陷智能诊断** | 最适合当前需求，数据现成、路线清晰 |
| **②** | **CircuitNet 版图拥塞与 DRC 风险预测** | 难度更高，获奖上限也更高 |
| **③** | **VisA + DeepPCB 少样本异常检测** | 容易实现，但赛题相关性略弱 |
| **④** | **假冒芯片检测** | 等有可靠样本来源后再考虑 |

> X-ray BGA 焊球检测的赛题契合度、创新性和展示效果都高于晶圆图分类，但因数据稀缺性，需先验证数据可得性再做决定。
